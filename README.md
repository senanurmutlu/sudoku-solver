An AI-powered Sudoku solver that extracts puzzles from images using Google Gemini OCR, converts them into a structured 9x9 grid, and solves them using SAT (PySAT). The application includes a Tkinter GUI and can find all possible solutions for a given Sudoku.

The goal of this project is to demonstrate how artificial intelligence (OCR) and constraint-based logic solving (SAT) can be combined to solve structured problems like Sudoku.

A valid Gemini API key is required and must be set as an environment variable (GEMINI_API_KEY).

Technologies used: Python, Google Gemini API, PySAT (Glucose3), Tkinter, Matplotlib, Pillow (PIL), Regular Expressions (regex), JSON processing.
